# boatyard

Tools and skills for running several Claude Code agents through one backlog, and for compacting an agent's context before it runs out.

Nothing here works yet.

boatyard is built to work beside [commy](https://github.com/CodeForBreakfast/commy), which carries the agents' messages, and [beady-eye](https://github.com/CodeForBreakfast/beady-eye), which watches them.
